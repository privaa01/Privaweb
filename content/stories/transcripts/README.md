# Transcripciones recibidas y ejercicios

Fuente: `TRANSCRIPCIONES.pdf`, entregado por la responsable del proyecto. El índice registra su SHA-256 y la correspondencia con las cuatro historias. Se conserva el PDF original y se extrae el texto de cada relato: solo se unen saltos de línea de maquetación y se retiran encabezados y saltos de página. Se mantienen expresiones orales y posibles errores del documento. No se afirma una comprobación independiente contra los audios.

| Número | Historia | Narradora / tema |
|---|---|---|
| 1 | La contraseña compartida | Luisa: tienda falsa y reutilización de contraseñas |
| 2 | La llamada sospechosa | Juliana: suplantación de WhatsApp y código de verificación |
| 3 | Enlace falso | Carolina: falsa adopción, datos personales y transferencias |
| 4 | Número desconocido | Salomé: suplantación bancaria por teléfono |

Los cuatro archivos de `../drafts/` contienen fichas compatibles con StoryDraft: transcripción, pregunta «¿QUÉ ERROR SE COMETIÓ?», tres opciones y una explicación de riesgo y prevención por opción. No incorporan puntuaciones ni señalan respuestas correctas o incorrectas. Las recomendaciones son contenido educativo redactado a partir del relato, no citas de la narradora.

Los ejercicios están pendientes de revisión editorial. Se ajustaron a los relatos: las opciones anteriores de referencia incluían una aplicación bancaria para la historia 2 y contraseñas anotadas en chats para la 1, hechos que no aparecen en estas transcripciones. Las alternativas propuestas se guardan como borradores sin cambiar automáticamente esas referencias ni las historias gestionadas.

Los IDs de recursos se mantienen nulos y el texto alternativo de portada vacío hasta seleccionar los medios mediante el flujo de gestión. Estos archivos no publican, activan ni actualizan registros en la base de datos. Para las tres historias iniciales se pueden preparar los medios con el importador autorizado existente; para Número desconocido se debe crear una ficha adicional con su portada. La publicación y activación siguen requiriendo los controles de gestión y revisión existentes.

Validación realizada: las cuatro fichas pasan `validateDraft` en modo borrador. Esto no certifica su preparación para publicar: los medios y la revisión editorial siguen pendientes.
