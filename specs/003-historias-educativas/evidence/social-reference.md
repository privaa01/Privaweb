# Perfil oficial de Instagram — 003/005

Fecha: 2026-10-26 (America/Bogota).

La responsable proporcionó explícitamente `https://www.instagram.com/priva_inc/` después de solicitarse el enlace al perfil de Priva. Se registra como destino oficial compartido de Historias y Contacto en `src/config/social.ts`.

Se comprobó el formato HTTPS, dominio www.instagram.com y ruta de perfil /priva_inc/, sin credenciales, parámetros ni fragmento. El estado verificado corresponde a la identificación del destino por la responsable y a esas comprobaciones locales.

Se intentó comprobar disponibilidad por HTTP HEAD, sin credenciales: el proxy del entorno rechazó el túnel CONNECT con403, sin respuesta HTTP del perfil de Instagram. No se acredita accesibilidad remota, estado de la cuenta, propiedad por OAuth ni ausencia de rastreo de Instagram. Esta limitación no invalida la URL proporcionada ni autoriza usar un perfil distinto.

No se modifican revisiones editoriales de otros textos ni el estado de recursos/materiales pendientes. No se inicia sesión, envía mensajes ni publica contenido en Instagram.
